# تراکم فنی (TECHNICAL_DEBT)

## ۱. خلاصه

این سند تمام تراکم‌های فنی شناخته شده، کوتاه‌دست‌ها (`shortcut:`)، کد مرده، محاسبات تکراری، مبهمیت‌های مالکیت حالت و بلوکرهای نگهداری در AlgoMultiAssetEA را کاتلوج می‌کند. هر مورد شامل شدت، مالک، اثر، و برنامه حل پیشنهادی است.

**اصل:** حذف بر اضافه کردن ترجیح دارد. تراکم P0–P1 باید در فاز مربوطه حل شود. تراکم P2–P3 برنامه‌ریزی شده یا پذیرفته شده با پذیرش ریسک صریح.
