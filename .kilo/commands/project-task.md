# Project Task — Compatibility Alias

This legacy command is retained temporarily for compatibility.

For new work, invoke `/project-engineering`. It now owns general task routing, baseline preservation, evidence-led investigation and implementation, conditional security review, conditional documentation work, validation and reporting formerly defined here.

Do not maintain a second independent process in this file. Apply `.kilo/commands/project-engineering.md` as the canonical instructions.

Use a narrower specialist Workflow when it clearly owns the task, such as `/ea-implement-validate`, `/ea-investigate-fix-validate`, `/ea-risk-review`, `/hybrid-lifecycle-implement-validate`, `/mt5-validate` or `/git-delivery`.
